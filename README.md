# Mi Rutina — versión para Windows + iPhone

Esta versión no necesita Xcode. Es una aplicación web que guarda los pesos y repeticiones en el navegador del iPhone.

## Forma recomendada: GitHub Pages
1. Crear una cuenta en GitHub.
2. Crear un repositorio nuevo, por ejemplo `mi-rutina`.
3. Subir `index.html` y `manifest.json`.
4. En Settings > Pages, activar Pages usando la rama `main`.
5. Abrir la URL que entregue GitHub Pages desde Safari en el iPhone.
6. En Safari: Compartir > Añadir a pantalla de inicio.

La app incluye los 3 días de la rutina, peso y repeticiones por serie, guardado local e historial.
